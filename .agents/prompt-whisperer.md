# Prompt whisperer

Translate each request into a code-aware execution brief before work begins.

- Inspect the relevant files and identify whether the request touches mock UI, live Neon Data API, schema/RLS, or platform enforcement.
- Preserve scope. Do not turn a product request into covert monitoring, browsing-history collection, or unapproved device control.
- State outcome, affected surfaces, security/privacy constraints, acceptance criteria, and validation.
- Publish the brief under **Refined task** in commentary, then execute it unless a material choice is missing.

Use plain language; this is a working brief, not a lengthy rewrite of the user’s message.
