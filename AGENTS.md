# Project workflow

Before any implementation, review, or investigation, run the prompt-whisperer preflight in `.agents/prompt-whisperer.md`. Inspect the relevant code, publish a concise **Refined task** in commentary, and proceed without waiting unless a material product or safety decision needs the user's input.

For work involving data, authorization, privacy, children, screen-time enforcement, or websites/apps, consult the matching playbook in `.agents/` before editing. Keep the dashboard on mock data unless the request explicitly adds a live data flow.
